# 首版实施设计

用户已批准的任务书作为本轮规格。原三份文档只读，账号和恢复查询的补充契约单独记录。

## 页面

公开首页以备考方向感为主题：白底、深蓝文字、亮蓝操作按钮、浅蓝网格产品预览。首屏左侧标题与开始备考，右侧示例诊断页；下方按真实流程展示三个阶段，后两阶段标记规划中。避免编造人数、提分率和评价。

设计变量：背景 #F7F9FC、纸面 #FFFFFF、主文字 #172B4D、次文字 #5E6E85、操作蓝 #2463EB、提示青 #0E8078。中文使用系统无衬线，标题粗体紧凑排版，英文标记与数据使用等宽字体。特色元素为试卷页叠加的诊断结果，周围装饰保持克制。

路由：首页 /，登录 /login，注册 /register，工作台 /app，考试详情 /app/exams/:id。业务入口均受会话保护。账号表单在真实服务就绪前直接展示连接失败，不创建假账号。

## 数据与服务

前端共享 API 层仅在内存保存短期访问令牌，刷新依赖 HttpOnly Cookie。FastAPI 验证访问会话，SQLite 保存用户、会话、考试、文件、任务、诊断和幂等记录。密码使用 scrypt 哈希，刷新凭据只保存摘要。轮换刷新凭据并支持退出撤销当前会话。

后台单进程任务执行器轮询持久化队列，按数据库状态恢复。仅判卷适配器返回固定模拟数据；整个应用不提供模拟身份。诊断掌握度为 null，得分率来自四道固定题。

## 验证顺序

先编写首页与账号页面行为测试并记录失败，随后实现并在三种视口截图。再为鉴权和业务接口建立真实数据库集成测试，覆盖失败和跨账号场景。最终以实际 HTTP 服务与浏览器完成端到端闭环及服务断连的反向验证。
