# 题库上传模块契约

日期：2026-09-18  
状态：需求契约草案  
适用范围：题库文件上传、公共与私人题库管理、公共试卷复制。题目解析与 AI 处理不属于本阶段。

## 1. 目标

本模块为 FinalBoost 增加按科目管理试卷文件的能力：

- 管理员上传、预览元数据、发布和下架公共试卷。
- 普通学生上传和查看自己的私人试卷。
- 普通学生浏览公共题库，并将公共试卷复制到自己的私人题库。
- 为后续 AI 解析题目、题型、答案和知识点保留稳定的试卷文件引用。

本阶段只负责 XLSX 文件及元数据的安全存储和权限管理，不解析工作簿中的题目内容。

## 2. 首版范围

### 2.1 纳入范围

- 由后端配置指定管理员账号。
- 系统标准科目和用户私人自定义科目。
- 一个科目下保存多份试卷。
- `.xlsx` 文件上传和基础结构校验。
- 公共试卷的草稿、发布和下架。
- 私人试卷上传、列表、详情和文件下载。
- 公共试卷检索、筛选和复制到私人题库。
- 上传、发布、下架和复制操作的幂等保护。
- 资源归属校验、容量限制和分页。

### 2.2 不纳入范围

- PDF、Word、图片、旧版 `.xls` 和含宏的 `.xlsm` 文件。
- OCR、题目拆分、题型识别、答案识别和知识点识别。
- 调用 AI 助手解析题库。
- 在线预览工作簿中的题目内容。
- 修改试卷元数据、替换文件和删除试卷。
- 将私人试卷转为公共试卷。
- 学生直接下载公共试卷的原始文件。
- 题库共享、协作编辑、审核流和版本历史。
- 科目别名及自动合并。

## 3. 术语和资源层级

题库是产品中的集合概念，不单独建立顶层题库实体。实际资源层级为：

```text
用户可访问的题库
  └─ 科目 Subject
      ├─ 试卷 Paper（XLSX）
      ├─ 试卷 Paper（XLSX）
      └─ 试卷 Paper（XLSX）
```

- **系统标准科目**：全体用户可见，仅管理员能够创建。
- **私人自定义科目**：仅创建它的学生可见和使用。
- **公共试卷**：管理员上传，发布后所有登录用户可搜索和复制。
- **私人试卷**：由学生上传，或由学生从公共试卷复制而来，仅所属学生可见。
- **源文件**：上传时保存的 XLSX 文件；本阶段不将其解析为独立题目。

一个科目可以关联多份试卷，一份试卷只能属于一个科目。

## 4. 用户、角色与权限

### 4.1 角色来源

系统保留 `student` 和 `admin` 两种角色。所有用户仍通过现有登录入口登录。

管理员由后端配置中的规范化用户名白名单指定。前端不得自行声明或修改角色，后端在登录、刷新会话和 `GET /auth/me` 响应中返回可信角色：

```json
{
  "userId": "user_001",
  "username": "admin",
  "role": "admin"
}
```

前端可依据角色显示入口，但所有权限必须由后端再次验证。未配置为管理员的账号统一视为 `student`。

### 4.2 权限矩阵

| 操作 | 学生 | 管理员 |
| --- | --- | --- |
| 查看系统标准科目 | 允许 | 允许 |
| 创建系统标准科目 | 禁止 | 允许 |
| 创建私人自定义科目 | 允许，仅自己可见 | 不需要 |
| 上传私人试卷 | 允许 | 允许 |
| 查看、下载自己的私人试卷 | 允许 | 允许 |
| 查看其他用户私人试卷 | 禁止 | 禁止，首版不提供越权入口 |
| 上传公共试卷 | 禁止 | 允许 |
| 查看公共草稿和已下架试卷 | 禁止 | 仅创建它的管理员允许 |
| 发布、下架公共试卷 | 禁止 | 仅创建它的管理员允许 |
| 浏览已发布公共试卷 | 允许 | 允许 |
| 下载公共试卷原始文件 | 禁止 | 仅创建它的管理员允许 |
| 将公共试卷复制到私人题库 | 允许 | 允许 |

普通用户访问他人私有资源或管理员资源时返回 HTTP 403；资源不存在时返回 HTTP 404。

## 5. 科目规则

### 5.1 混合科目模型

科目分为：

- `system`：系统标准科目，全局共享，`ownerUserId` 为空。
- `private`：用户私人科目，仅所属用户可见，`ownerUserId` 为创建用户。

公共试卷只能关联系统标准科目。私人试卷可以关联系统标准科目或当前用户的私人科目。

### 5.2 名称规范化和唯一性

科目名称长度为 1～100 个字符。后端执行以下规范化：

1. 去除首尾空白。
2. 将连续空白折叠为一个空格。
3. 英文字母使用不区分大小写的比较值。

约束：

- 系统标准科目的规范化名称全局唯一。
- 私人科目的 `ownerUserId + normalizedName` 唯一。
- 学生提交的名称若已匹配系统标准科目，应复用系统科目，不再创建私人同名科目。
- 学生提交的名称未匹配系统标准科目时，可以创建仅自己可见的私人科目。
- 管理员上传公共试卷时，可以选择已有系统科目，也可以创建新的系统标准科目。

首版不自动处理“高数”和“高等数学”等语义别名。

## 6. 试卷元数据

每份试卷包含：

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `paperId` | string | 响应字段 | 服务端生成的不透明 ID |
| `subjectId` | string | 是 | 必须是当前操作允许使用的科目 |
| `name` | string | 是 | 去除首尾空白后 1～200 字符 |
| `college` | string | 是 | 去除首尾空白后 1～100 字符 |
| `year` | integer | 是 | 四位年份，1900～2100 |
| `semester` | string | 是 | 去除首尾空白后 1～30 字符 |
| `visibility` | enum | 是 | `private` 或 `public` |
| `publicationStatus` | enum/null | 响应字段 | 公共试卷为 `draft/published/unpublished`；私人试卷为 null |
| `fileId` | string | 响应字段 | 受保护的 XLSX 文件引用 |
| `fileName` | string | 响应字段 | 清理路径后的展示文件名 |
| `fileSize` | integer | 响应字段 | 文件字节数 |
| `sourcePublicPaperId` | string/null | 响应字段 | 从公共试卷复制时记录来源，否则为 null |
| `createdAt` | datetime | 响应字段 | 带时区时间 |
| `publishedAt` | datetime/null | 响应字段 | 最近一次首次发布的时间 |

`semester` 首版使用文本，例如“第一学期”“第二学期”或“春季学期”，不建立固定枚举。

## 7. 文件规则

- 首版只接受 `.xlsx`，单文件最大 20 MiB。
- 后端必须校验文件扩展名、ZIP 容器和 XLSX 必需结构，不能只信任 MIME 类型。
- 文件必须能被安全打开，并至少包含一个工作表。
- 拒绝损坏文件、加密文件、旧版 `.xls`、含宏的 `.xlsm` 和伪装成 XLSX 的内容。
- 不执行公式、宏、外部链接或嵌入对象。
- 上传文件名只用于展示，不能参与服务端磁盘路径计算。
- 存储键由服务端生成，数据库只保存安全存储引用。
- 公共源文件不向普通学生暴露下载 URL。
- 私人文件的下载接口必须验证当前登录用户是试卷所有者。
- 管理员只能下载自己上传的公共源文件，首版不提供跨管理员读取。

本阶段只验证文件是安全且可读取的 XLSX，不校验表头、题目行、题型、答案或知识点。

## 8. 容量限制

- 普通学生最多拥有 100 份私人试卷。
- 自行上传和从公共题库复制的试卷都计入该限制。
- 达到上限后，新上传和复制均被拒绝，不产生文件或试卷记录。
- 管理员公共试卷首版不设数量上限。
- 分页接口默认 `limit=20`，最大 `limit=100`。

## 9. 公共试卷生命周期

```text
上传成功
   ↓
 draft ──发布──> published ──下架──> unpublished
                    ↑                    │
                    └────再次发布────────┘
```

- 管理员上传公共试卷成功后状态为 `draft`，不会自动公开。
- 管理员通过详情确认元数据和文件信息后主动发布。
- 只有 `published` 状态的公共试卷能被普通学生搜索和复制。
- 下架后的试卷不再出现在公共列表，也不能产生新的私人副本。
- 下架不影响已经复制成功的私人副本。
- 首版允许已下架试卷再次发布。

## 10. 公共试卷复制规则

- 复制会为当前用户创建新的私人试卷记录和独立的受保护文件记录。
- 新副本复制公共试卷当时的科目、名称、学院、年份、学期和文件内容。
- 副本记录 `sourcePublicPaperId` 用于来源追踪。
- 复制完成后，公共试卷的修改、下架或未来删除均不得影响已有私人副本。
- 实际存储层可以复用不可变内容，但权限、生命周期和资源记录必须相互独立。
- 同一用户不能重复复制同一公共试卷。
- 对同一来源重复复制时，接口返回首次创建的私人副本，不创建重复记录。
- 复制得到的试卷计入用户 100 份私人试卷限制。
- 学生不能直接下载公共源文件；只有复制成功后才能下载自己的私人副本。

## 11. API 契约

所有路径相对 `/api/v1`。JSON 接口沿用现有 `{code,message,data,requestId}` 封装。所有创建或状态变更请求必须携带 1～128 字符的 `Idempotency-Key`。

### 11.1 查询可用科目

`GET /subjects?q={keyword}&limit=20&cursor={cursor}`

学生获得系统标准科目及自己的私人科目；管理员获得系统标准科目。`q` 对规范化名称做包含搜索。

响应 data：

```json
{
  "items": [
    {"subjectId":"subject_001","name":"数据结构","scope":"system"}
  ],
  "nextCursor": null
}
```

### 11.2 创建私人科目

`POST /subjects/private`，成功返回 201。

请求：

```json
{"name":"计算机图形学专题"}
```

如果规范化名称已匹配系统标准科目或当前用户的私人科目，返回已有科目，不重复创建。

### 11.3 创建系统标准科目

`POST /subjects/system`，仅管理员可调用，成功返回 201。

请求：

```json
{"name":"高等数学"}
```

相同规范化名称重复提交返回已有科目。

### 11.4 上传试卷

`POST /papers`，`multipart/form-data`，成功返回 201。

表单字段：

| 字段 | 说明 |
| --- | --- |
| `file` | XLSX 文件 |
| `subjectId` | 已有科目 ID |
| `name` | 试卷名称 |
| `college` | 学院 |
| `year` | 年份 |
| `semester` | 学期 |
| `visibility` | `private` 或 `public` |

学生只能提交 `private`。管理员提交 `public` 时，试卷创建为 `draft`。

响应 data 示例：

```json
{
  "paperId":"paper_001",
  "subject":{"subjectId":"subject_001","name":"数据结构","scope":"system"},
  "name":"2025 数据结构期末试卷",
  "college":"计算机与人工智能学院",
  "year":2025,
  "semester":"第一学期",
  "visibility":"public",
  "publicationStatus":"draft",
  "fileId":"file_001",
  "fileName":"data-structures-2025.xlsx",
  "fileSize":83214,
  "sourcePublicPaperId":null,
  "createdAt":"2026-09-18T11:00:00+08:00",
  "publishedAt":null
}
```

文件写入、文件记录和试卷记录必须作为一个原子操作处理。任一步失败时不得留下不可达文件或半成品记录。

### 11.5 查询私人试卷

`GET /papers/private?subjectId=&q=&year=&semester=&limit=20&cursor=`

- 只返回当前用户的私人试卷。
- `q` 搜索试卷名称。
- 默认按创建时间从新到旧排列。

### 11.6 查询私人试卷详情

`GET /papers/private/{paperId}`

只允许试卷所有者访问。响应包含受保护的 `downloadUrl`。

### 11.7 下载私人试卷

`GET /papers/private/{paperId}/file`

只允许试卷所有者下载，响应使用 XLSX MIME 类型和安全的 `Content-Disposition` 文件名，并设置 `Cache-Control: private, no-store`。

### 11.8 查询管理员公共试卷

`GET /admin/papers?status=&subjectId=&q=&year=&semester=&limit=20&cursor=`

仅管理员可调用，只返回当前管理员创建的公共试卷，包括草稿、已发布和已下架状态。

### 11.9 查询管理员公共试卷详情和源文件

- `GET /admin/papers/{paperId}`：查询详情。
- `GET /admin/papers/{paperId}/file`：下载源 XLSX。

仅创建该试卷的管理员可访问。

### 11.10 发布公共试卷

`POST /admin/papers/{paperId}/publish`，请求体 `{}`，成功返回 200。

- `draft` 或 `unpublished` 可以发布。
- 已经为 `published` 时幂等返回当前结果。
- 发布时再次确认源文件存在。

### 11.11 下架公共试卷

`POST /admin/papers/{paperId}/unpublish`，请求体 `{}`，成功返回 200。

- 只有 `published` 可以下架。
- 已经为 `unpublished` 时幂等返回当前结果。
- 不影响现有私人副本。

### 11.12 浏览公共试卷

`GET /public/papers?subjectId=&college=&year=&semester=&q=&limit=20&cursor=`

- 只返回 `published` 状态。
- `q` 按试卷名称关键词搜索。
- 支持科目、学院、年份和学期筛选。
- 默认按发布时间从新到旧排列。
- 响应不包含 `fileId`、`downloadUrl`、存储键或其他可用于直接下载源文件的信息。
- 每项返回当前用户是否已复制以及已有私人副本 ID。

示例：

```json
{
  "items":[
    {
      "paperId":"paper_public_001",
      "subject":{"subjectId":"subject_001","name":"数据结构","scope":"system"},
      "name":"2025 数据结构期末试卷",
      "college":"计算机与人工智能学院",
      "year":2025,
      "semester":"第一学期",
      "publishedAt":"2026-09-18T11:30:00+08:00",
      "copied":true,
      "privatePaperId":"paper_private_001"
    }
  ],
  "nextCursor":null
}
```

### 11.13 复制公共试卷

`POST /public/papers/{paperId}/copy`，请求体 `{}`，成功返回 201。

- 只能复制当前处于 `published` 状态的试卷。
- 新副本归当前用户所有，`visibility=private`。
- 重复复制返回第一次创建的私人副本，HTTP 状态与首次幂等响应保持一致。
- 文件记录、试卷记录和来源唯一关系必须在同一事务中创建。

## 12. 幂等与并发

- `POST /subjects/private`、`POST /subjects/system`、`POST /papers`、发布、下架和复制均要求 `Idempotency-Key`。
- 24 小时内同用户、同方法、同路径、同键、同请求返回首次响应。
- 同一幂等键对应不同请求内容时返回 HTTP 409。
- multipart 上传的请求摘要至少包含文件 SHA256、文件展示名和全部元数据。
- 数据库唯一约束必须防止并发创建重复科目和重复公共试卷副本。
- 同一用户和公共试卷的复制关系唯一。

## 13. 错误约定

| HTTP 状态 | 场景 |
| --- | --- |
| 400 | 字段缺失、年份非法、名称为空、请求验证失败 |
| 401 | 未登录或会话失效 |
| 403 | 角色不符、访问他人资源、学生尝试上传公共试卷 |
| 404 | 科目、试卷或文件不存在 |
| 409 | 幂等冲突、非法状态转换、并发冲突 |
| 413 | XLSX 超过 20 MiB |
| 415 | 文件类型不支持或不是真实 XLSX |
| 422 | XLSX 损坏、加密、含宏或结构不可安全读取 |
| 500 | 未预期服务错误 |

建议的领域错误码：

| code | 含义 |
| --- | --- |
| 40910 | 当前用户已复制该公共试卷 |
| 40911 | 当前状态不允许发布 |
| 40912 | 当前状态不允许下架 |
| 40913 | 私人试卷数量已达 100 份 |
| 41310 | XLSX 文件超过 20 MiB |
| 41510 | 只支持 `.xlsx` 文件 |
| 42210 | XLSX 文件损坏或无法读取 |
| 42211 | XLSX 文件已加密 |
| 42212 | XLSX 包含宏或不安全结构 |
| 42213 | XLSX 不包含工作表 |

错误仍使用现有统一封装：

```json
{
  "code":40913,
  "message":"私人题库最多保存 100 份试卷",
  "data":null,
  "requestId":"request_001"
}
```

## 14. 前端页面与流程

建议路由：

```text
/app/question-bank                 私人题库
/app/question-bank/upload          上传私人试卷
/app/question-bank/public          公共题库
/app/question-bank/papers/:id      私人试卷详情
/app/admin/question-bank           管理员公共试卷管理
/app/admin/question-bank/upload    管理员上传公共试卷
```

学生流程：

```text
选择已有科目或输入新私人科目
  → 填写试卷名称、学院、年份、学期
  → 选择 XLSX
  → 上传成功
  → 在私人题库按科目查看和下载
```

公共复制流程：

```text
搜索公共试卷
  → 按科目/学院/年份/学期筛选
  → 加入私人题库
  → 显示“已加入私人题库”
  → 从私人试卷详情下载独立副本
```

管理员流程：

```text
选择或创建系统标准科目
  → 填写元数据并上传 XLSX
  → 查看草稿元数据
  → 发布
  → 必要时下架或重新发布
```

## 15. 数据模型建议

### subjects

```text
id
name
normalized_name
scope                 system / private
owner_user_id         system 时为空
created_at
```

唯一约束：

- `system(normalized_name)` 唯一。
- `private(owner_user_id, normalized_name)` 唯一。

### papers

```text
id
owner_user_id
subject_id
name
college
year
semester
visibility            private / public
publication_status    draft / published / unpublished / null
file_id
source_public_paper_id
created_at
published_at
updated_at
```

关键约束：

- 私人试卷的 `owner_user_id` 必填，`publication_status` 为空。
- 公共试卷的所有者必须是管理员，科目必须为 `system`。
- `source_public_paper_id` 仅复制产生的私人试卷使用。
- `(owner_user_id, source_public_paper_id)` 在来源非空时唯一。
- 文件记录必须归属同一试卷所有者，并标明用途为题库 XLSX。

管理员角色来自运行时后端配置，不依赖数据库中的可由客户端修改字段。

## 16. 与未来 AI 解析的边界

本模块为未来解析保留以下信息：

- 稳定的 `paperId` 和 `fileId`。
- 文件 SHA256、MIME、大小和安全存储位置。
- 科目、学院、年份和学期。
- 公共来源与私人副本之间的来源关系。

未来 AI 解析应建立独立异步任务和结构化题目表，不修改本契约中的上传语义。建议未来增加：

```text
paper_parse_jobs
questions
question_assets
knowledge_points
question_knowledge_points
```

解析失败不能破坏或删除原始试卷文件；重新解析应基于同一 `paperId` 创建新任务。

## 17. 验收场景

- 学生能选择系统科目并上传私人 XLSX。
- 学生能创建系统不存在的私人科目并上传试卷。
- 学生不能重复创建与系统标准科目同名的私人科目。
- 一个科目下可以保存多份试卷。
- 学生能查看、筛选和下载自己的私人试卷。
- 学生不能读取或下载其他学生的私人试卷。
- 非管理员不能上传、发布或下架公共试卷。
- 管理员能创建系统科目并上传公共草稿。
- 公共草稿不会出现在学生公共题库中。
- 管理员发布后，学生能按名称、科目、学院、年份和学期找到试卷。
- 公共列表及详情不泄露源文件下载地址。
- 学生复制公共试卷后能下载自己的独立副本。
- 同一学生不能重复复制同一公共试卷。
- 管理员下架公共试卷后无法产生新副本。
- 下架不影响已经复制的私人副本。
- 非 XLSX、损坏 XLSX、加密 XLSX、含宏文件和超大文件被明确拒绝。
- 学生达到 100 份私人试卷后，上传和复制均被拒绝。
- 相同幂等键重复上传、发布、下架和复制不会产生重复数据。
- 服务重启后科目、试卷、发布状态和文件仍然可用。
