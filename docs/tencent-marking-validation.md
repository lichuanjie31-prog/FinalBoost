# 腾讯云高数批改独立验证

日期：2026-09-17

## 当前状态与执行顺序

用户确认先做供应商能力验证，通过后再接后端、原卷工作台和文本辅导。

- 第一阶段：待开通服务、核对授权与费用，尚未进行真实请求。
- 第二阶段：暂缓。已有未提交的适配器草稿和离线测试，它们不能证明高数识别、批改或坐标准确。
- 第三阶段：暂缓，尚未实现原图批注界面。
- 第四阶段：暂缓，仅在批改证据经过核对后调用文本模型解释。

当前终端未检测到 TENCENTCLOUD_SECRET_ID / TENCENTCLOUD_SECRET_KEY。此检查仅代表当前进程环境，不代表用户电脑其他位置没有凭据。API Explorer 可在登录后使用控制台授权进行调试，切勿把密钥写入截图、测试记录或 Git。

## 官方入口

- 提交任务文档：https://cloud.tencent.com/document/product/866/128273
- 提交调试入口：https://console.cloud.tencent.com/api/explorer?Product=ocr&Version=2018-11-19&Action=SubmitQuestionMarkAgentJob
- 查询文档：https://cloud.tencent.com/document/product/866/128274

腾讯云文档主要面向 K12。本次验证只用于决定高数首版是否可用，不能由少量样例推出所有大学课程均可用。

## 开通前核对

由账号持有人确认已开通对应的试题批改 Agent 服务，登录 API Explorer 并选择正确账号。核对当前控制台显示的计费方式、资源包可用范围、是否存在试用额度及调用权限。记录实际显示的信息，不假定普通 OCR 额度能用于此接口。收费开通或购买资源包由用户确认操作。

## 测试输入

先用一页真实高数作答，纸面上同时包含题干与学生手写过程。选择已由人工核对的正确题、错误题和多步计算题。保留原始照片，首次测试使用清晰、正向、无裁切的 JPEG 或 PNG，建议至少 600 × 800 像素。

如需可控样例，可以把以下自编题目及指定作答写在一张纸上。它们仅作为测试输入，不作为模型输出或测试通过证明。

| 题号 | 题目 | 指定作答 | 人工判定与依据 |
| --- | --- | --- | --- |
| 1 | 求 f(x)=x³+2x 的导数 | f′(x)=3x²+2 | 正确 |
| 2 | 求不定积分 ∫2x dx | x² | 不完整，缺少任意常数 C |
| 3 | 求定积分 ∫₀¹ x² dx | [x³/3]₀¹=1/3 | 正确，步骤与结果一致 |
| 4 | 求极限 lim(x→0) sin(2x)/x | sin(2x)/x=[sin(2x)/(2x)]×2→1 | 错误，最后一步应为 2 |
| 5 | 求 ∫x eˣ dx | 令 u=x，dv=eˣdx，则 du=dx，v=eˣ；原式=xeˣ−∫eˣdx=(x−1)eˣ+C | 正确，多步分部积分 |
| 6 | 求 y=e^(x²) 的导数 | 留空 | 未作答，不应判为正确 |

将正确参考解答写在另一张纸上拍照，供第二轮辅助批改。参考解答中第 2 题写 x²+C，第 4 题写极限为 2，第 6 题写 y′=2xe^(x²)。

## 第一轮，无参考答案

API Action 使用 SubmitQuestionMarkAgentJob。

- ImageBase64 填入图片 Base64 编码的纯内容，或使用供应商可访问的 ImageUrl。
- 本地 localhost 地址和 FinalBoost 需要登录的图片 URL 无法直接作为供应商图片地址。
- Base64 编码后不能超过文档的 10M 限制。
- AssistMarkType 使用 0。
- QuestionConfigMap 是 JSON 字符串，内容如下。

```json
{"KnowledgePoints":true,"TrueAnswer":true,"StepCorrection":true,"OutputSubQuestionsAndCoords":true}
```

保存提交响应的 JobId 和 RequestId。随后使用 DescribeQuestionMarkAgentJob 查询同一 JobId，等待 WAIT / RUN 转为 DONE 或 FAIL。避免连续高频查询；本轮可每 10 秒手动查询一次，实际以控制台限额为准。提交成功后只查询，不重复提交同一图片。

保存最终原始 JSON。不要只保存截图或助手总结。

## 第二轮，有参考答案

保持学生作答图片完全相同，使用 AssistMarkType=2，并按官方参数定义在 ImageBase64List 或 ImageUrlList 中提供参考答案图片。学生作答图片仍使用 ImageBase64 或 ImageUrl。不要将多页随意塞入列表，非辅助模式下列表可能用于拼接跨页题。

ReferenceAnswer 字段仅对单题有效，本轮整页辅助不要依赖该字段。

记录新的 JobId / RequestId，与第一轮逐题对照。若服务未开通、权限不足或计费状态异常，先解决账号问题，这类失败不计入模型能力评估。

本批样例要求上述项目通过后再进入第二阶段。它是接入门槛，不是整体准确率承诺。通过后追加真实高数样卷；若错误集中于高数题型，先缩小范围或更换供应商，避免用演示分掩盖失败。

批改坐标可能为空。遇到缺坐标应保留题目文字并标记不能在原图定位。遇到非零 Angle，必须实际核对坐标相对于哪张图，不先假设旋转方向或坐标系。

服务没有提供评分细则时，只验正误与解析。不要把正确答案区域数量直接换算成百分制成绩，也不要把它解释为知识掌握度。

## 通过后的实现边界

第二阶段复用现有上传和判卷任务入口，保存供应商标识、原始结果、标准化题目与坐标。提交和轮询调用在数据库事务之外执行。重复提交使用持久化幂等标识，提交超时导致结果未知时禁止自动重复扣费请求。

第三阶段提供左侧原图、右侧题目详情；实现页面切换、缩放、批注开关和错题定位。批注使用可关闭的覆盖层，保存原图；坐标为空或未验证时只显示列表。

第四阶段向文本辅导模型传递经过核对的题干、作答与批改意见。辅导建议单独记录模型和来源，不覆盖供应商的原始批改结果。
